zh-TW: 刪除筆記後，筆記樹會停在原位：被刪的那列消失、下面的列往上補，正在看的筆記刪掉後會改開旁邊的一篇，可以一篇接一篇刪。手機刪除後回到清單，也停在原來的位置。
en: After you delete a note, the note tree stays where it was: the row disappears and the rows below move up. If you deleted the note you were reading, the one next to it opens, so you can delete several in a row. On a phone, you return to the list at the same spot.
