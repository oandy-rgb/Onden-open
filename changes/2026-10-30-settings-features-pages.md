zh-TW: 白板和各種檢視一樣一律開著，設定裡不再有白板的開關，用「＋」就能加。設定的「功能」改成一份清單：圖示、名稱、開關，點一列就進到那個功能自己的頁，它的設定都在那裡（日記的換日時間、閱讀的存放位置、收件匣的捕捉位置）。外觀有即時預覽，導覽列頁會先畫出真正的導覽列。
en: The whiteboard is always on, like the views, so Settings no longer has a switch for it — add it with "+". Settings › Features is now one list — icon, name, switch — and a row opens that feature's own page with all of its settings (Daily notes' day start, Reading's save place, Inbox's capture place). Appearance has a live preview, and the Navigation bar page draws the real bar first.
