en: Skills are no longer a tag. Turn on “Use as a skill” in a note's info panel — #技能 no longer shows in tag rows or search. Each skill has a “Let the AI use it” switch, and the AI picks the ones that are on by itself when they fit. Settings › Features › Skills lists them all, and a tag page lists the skills used there.
