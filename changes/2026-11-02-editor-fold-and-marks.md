zh-TW: 筆記裡的標題可以收起底下的整段：點標題後面的小箭頭、或用指令面板的「全部收起標題」；收起的地方點「…」就展開，下次開啟這篇還記得（只記在這台裝置）。另外，選一個詞會淡淡標出同一篇裡一樣的字；寫到筆記最後時，游標會離開畫面最底；電腦上按住 Alt 拖曳可以一次選多行同一欄。
en: Headings in a note can now fold away their whole section — use the small arrow after a heading or "Collapse all headings" in the command palette; tap "…" to open it again, and this device remembers it. Selecting a word faintly marks the same text elsewhere in the note, the cursor rises off the bottom edge when you write at the end, and on a computer Alt + drag selects the same column across several lines.
