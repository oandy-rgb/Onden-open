zh-TW: 什麼都沒改的時候不再多出一個歷史時間點：打字又刪回原樣、按下儲存但內容沒變、重新命名成同樣的名字、打開有殘留隱藏標記的筆記，都不會留下新版本；歷史裡以前累積的重複時間點也合併成一個，時間軸最右邊也不會再多一個和最新版一模一樣的「現在」。
en: Nothing changed now means no new history point: typing and deleting back to the same text, saving with no change, renaming to the same name, or opening a note with leftover hidden markers no longer leaves a new version. Duplicate points that built up in history are merged into one, and the time slider no longer adds a “Now” that is identical to the latest version.
