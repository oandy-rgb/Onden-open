zh-TW: 「回到這個版本」現在預設只換回內文，不會悄悄把筆記改回舊標題；版本不同標題時，會在版本旁標出「標題：…」，並讓你勾選「也把標題改回…」。只改標題的紀錄也會寫成「標題從…改名」。
en: "Go back to this version" now brings back only the text by default and no longer renames the note silently. When a version had another title it is shown as "Title: …", and you can tick "Also change the title back to …".
