zh-TW: 用檔案把筆記帶到另一台裝置時，筆記的舊版本現在也會一起帶過去；筆記先到、先能用，舊版本接著補上。如果舊版本沒有全部到，畫面會直接說，並讓你再選一次同一個檔案接著收，或不再等它們；在那之前這台裝置不能再拿來帶給第三台。瀏覽器版遇到很大的手寫舊版本時，只帶文字的舊版本，畫面也會說明；從這樣的裝置再帶給別台，那台也會說手寫的舊版本沒有帶過來。檔案中途斷掉時，畫面照這台實際的狀態說：筆記到了就說筆記都在。以前用檔案帶過來、沒有舊版本的裝置，設定裡會說明這件事；再拿一個原本那台做的檔案就能只補進舊版本，筆記不會改，補完之前這台不能再做檔案給別台。
en: Bringing your notes to another device with a file now brings their earlier versions too: the notes arrive and work first, the earlier versions follow. If they don't all arrive, the screen says so and lets you choose the same file again to finish, or stop waiting for them; until then that device can't bring notes to a third one. When handwriting's earlier versions are very large, the browser version keeps the earlier versions of the text only, and says so; a device that gets its notes from such a one says so too. When a file is cut short, the screen says what the device really holds: once the notes are in, it says they are. A device that got its notes from a file before this, and so has no earlier versions, now says so in Settings; a new file from the original device brings in just the earlier versions without changing the notes, and until then that device can't make a file for another one.
