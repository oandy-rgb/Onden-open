## 4. 「這一天」項目的合併規則（契約，給畫面批）

「這一天」的過去部分是自動記下的「發生」，必須讀得出一天做了什麼，又不能變成一串雜訊或一張成績單：

1. **連續修改合成一段**：同一篇筆記（或同一個任務）在短時間內的連續編輯合成一個項目，時間取第一次到最後一次，
   不是每次存檔一列。
2. **只留地標**：建立／完成一個任務、專注一段、第一次寫某篇、移動一件事。游標移動、小改字、排序不留。
3. **不做忙碌罪惡感的數字**：不顯示「今天只做了 N 件」「專注 N 分鐘低於平均」「連續 N 天」這類數字、排名或進度條；
   空的一天就是空的一天。專注的總長度可以在紀錄本身看到，但不拿來評分。
4. **發生的來源**：完成（`_task_done_at`）、專注（`focus_sessions`）、筆記建立／編輯（事件）。
   未來的部分來自有時間的任務（`_task_time`／`_task_until`），沒有結束時間的顯示一個預設長度。
5. **時間軸只顯示任務與專注**（2026-10-31）：上面 1 的合併規則仍用於「這天發生的」與歷史；時間軸不再顯示修改／建立／AI 執行等「發生」。
6. 這些項目的資料格式由 `feat/day-timeline` 定；本批只保證上面的來源欄位存在且可靠。

## 6. 參考

| 來源 | 學到什麼 |
| --- | --- |
| **Structured** | 時間軸上的任務有開始與結束，按真實比例畫，並有「現在」線；無時間的任務放在時間軸外的一區。 |
| **Sunsama** | 每天有一個收工的儀式：把沒做完的決定移到明天或放掉，而不是任它堆積（本專案已有「收工」，本批讓每天都留下紀錄）。 |
| **NotePlan** | 任務與日記是同一份文字：任務就是日記裡的一行，時間寫在行首（`15:00-16:00`）。文字是依據，介面改的是文字。 |
| **Obsidian Day Planner** | 同樣把時間區間寫在 Markdown 行首並畫成時間軸，證明這種語法夠簡單、使用者看得懂也能手改。 |
| **TickTick** | 專注（番茄鐘）的紀錄與任務綁在一起，完成後在時間線上留下一段，而不是只有計數。 |
| **Session**（專注計時 app） | 結束時問「做了什麼」，事後可以修正忘了停的時間；紀錄是可編輯的事實，不是不可改的成績。 |
| **Day One** | 日記以「一天」為單位，自動帶入當天發生的事（地點、照片、活動），讀的人像讀日記而不是讀日誌。 |

## 8. 2026-10-31 改版：日記單天頁

業主用手機看過「日記」頁：「在這頁本身做不了什麼事情」「比起日記更像是日曆」。參考 Logseq、NotePlan、Capacities、
Tana、Things、Day One 後的決定：**日記＝單天頁**，時間軸與規劃搬到任務頁。資料模型、API、任務寫入路徑、快速捕捉、
日記筆記建立規則都沒動；只改畫面的分工。

### 8.1 日記頁（`?view=daily`，`modules/daily/JournalScreen` ＋ `day/DayPage`）

- 一次只看一天，不是往下捲的日記流。那天的日記內文用 `MarkdownRenderer` **整篇渲染**（唯讀，再長也不截）；
  點內文（空白處或文字）跳到那天的日記筆記（`onOpenNode`）；內文裡的連結、按鈕照常，只去連結目標，不觸發開日記。
  右上角的「開啟」按鈕是同一件事的鍵盤入口。
- 沒有日記（或內容空白）的日子顯示「寫點什麼…」：沒有筆記時走 `dayNotes.openDay(date)` 建立並打開（同一個入口，連點不會重複建）；
  已有空白筆記就直接打開它。
- 日期導覽：標題兩側 ‹ ›（前一天／後一天）；標題下小字「今天／昨天／明天／還沒到」；上方週列（週一開頭，
  有東西的日子打點）＋可展開月曆（`DayStrip`）；不在今天時有「回到今天」。
- **選中的日子記在 `daily/pickedDay.ts`**（只在本次使用中、只對「那一個今天」有效）：開筆記會離開這一頁，
  返回時回到同一天，不跳回今天；過了午夜就從新的今天開始。
- 內文下面固定三區，沒有內容的區不顯示，三區都空時一行「這天沒有任務、記錄，也還沒有筆記提到它。」（`day/DaySections`）：
  1. **這天要做的**（任務模組開著才有）：`when_date` 是這天的任務（含 note-task），用 `JournalTasksRow` 直接打勾，
     第二行是時間與所在筆記（同一份 `useDayItems` 的 task 項目，不另算一套）。今天這區底下一行
     「接下來 HH:MM 標題」（今天還沒完成、有時間、在現在之後的最早一件；沒有就不顯示）和連結「時間軸、收工 ›」到任務頁
     （`ModuleScreenProps.onOpenView("tasks")`）。
  2. **這天發生的**：那天日記的快速記錄（`dayChildren`）＋當天「建立」「修改」的筆記（`GET /api/day/:date/lens` 的
     `created`／`edited`，`useDayLens`；不列日記本身、不重複列快速記錄；先 5 篇，其餘「還有 N 篇」可展開）。
     離線或沒權限時只剩快速記錄。
  3. **提到這天的**：連到那天日記筆記的反向連結（`noteNeighborhood` 的 backlinks，和筆記頁「被 N 篇筆記提到」同一份），
     顯示標題與提到那句的片段（`BacklinkSnippetView`，和筆記頁共用）。**不做**內文日期辨識（之後另案）。
- 另外保留「去年今天」卡（`LastYearCard`）。
