# 提案：桌面版用一個按鈕，讓這台電腦上的 AI 回答問題

> 狀態：提案（2026-11-15）；實作在 `feat/desktop-ai-answering`，疊在 `feat/ai-answering-program`（正式的回答程式）之上。

## 1. 一句話

**桌面版「設定 › AI」多一個按鈕：打開它，這台電腦上已登入的命令列 AI 工具就會替你的 Onden 回答筆記旁的問題；關掉它，就停止並撤銷連線碼。**
用的是你自己的 AI 訂閱，不是 API 金鑰；不需要自己寫腳本。

## 2. 兩個對象

| | A：這個桌面版自己的筆記 | B：另一台 Onden 伺服器（業主現在的情形） |
| --- | --- | --- |
| 筆記在哪 | 桌面版內建的後端（只聽 127.0.0.1） | 別處的伺服器；這台電腦只負責回答 |
| 連線碼怎麼來 | 按鈕替你建立 AI 與連線碼（走既有的「新增 AI」操作，以目前登入的擁有者） | 你在伺服器的網頁建立 AI，把「網址」與「連線碼」貼進桌面版一次 |
| 連線碼放哪 | 桌面版的保護儲存（Electron `safeStorage`）；不顯示、不進網頁的儲存、不寫記錄 | 同左 |
| 關掉 | 停止回答、忘掉連線碼、撤銷伺服器上的連線碼 | 停止回答、忘掉連線碼；伺服器上的連線碼請在伺服器的 AI 卡片撤銷（桌面版沒有那台伺服器的登入） |

**B 的兩種做法**：(a) 貼上網址與連線碼一次；(b) 在瀏覽器按「核准」，由伺服器把連線碼發給桌面版。
**做 (a)。** (b) 需要伺服器新增「配對請求」資料、核准畫面、輪詢或回呼，每一塊都牽動權限與稽核，不算「小而安全」；(a) 只用既有的連線碼，沒有新的伺服器行為。
(b) 之後要做時，只是「連線碼從哪來」變了，儲存與回答這兩層不用動。網址必須是 `https://`，或這台電腦／內網位址（`http://127.0.0.1`、`192.168.x.x` 等）；存之前先把網址原樣顯示給你確認，並用這把連線碼試連一次。

## 3. 程式放哪

- 回答程式本身在 `packages/ai-answerer`（PR 1），桌面版的主程序直接 import，**不另寫第二套**；打包時 `stage.mjs` 把它複製成 `resources/ai-answerer`。
- 主程序新增 `packages/desktop/src/aiAnswering/`：`store.mjs`（加密儲存）、`controller.mjs`（開／關／狀態，管理兩個對象各一條回答迴圈）、`bridge.mjs`（網頁能呼叫的那幾個動作，逐項驗證參數）；`preload.cjs` 只把這幾個動作交給網頁。
- 回答迴圈跑在主程序裡（不是新的子程序）：App 開著才回答；App 關閉時停止 AI 工具並清掉暫存。重新開啟時，開著的對象自動恢復。
- 網頁端：`lib/desktopBridge.ts`（取得橋接，沒有就是 `null`）與 `settings/ai/ThisComputerAnswering.tsx`（延後載入的設定畫面）。

## 4. 網頁與桌面外殼之間的橋（只有這些）

`window.ondenDesktop.ai`：`detect()`、`status()`、`previewAddress(text)`、`enableOwn({ actorId, code, codeId? })`、`disableOwn()`、`enableRemote({ address, code })`、`disableRemote()`、`onStatus(callback)`。
每個參數都在主程序驗證（型別、長度、連線碼格式、網址規則）；橋**不能**執行任意命令、不能讀任意檔案、不能指定要啟動哪個程式。`code` 只往主程序走一次，不會回來。
一般瀏覽器沒有這個橋：這一區整個不出現（不顯示檔名或說明文件的名稱）。橋只回應 App 自己位址的主框架、且網址不在 `/api/` 底下（使用者上傳的內容在那裡，同一來源但不是 App 的畫面）；`enableOwn` 另帶伺服器上那把碼的編號 `codeId`（不是秘密），關掉時只作廢它，不動使用者為別台電腦另做的碼。

## 5. 使用者在每個狀態看到什麼

| 狀態 | 畫面 |
| --- | --- |
| 一般瀏覽器 | 這一區不出現 |
| 找不到 AI 工具 | 「這台電腦上找不到命令列 AI 工具。請先安裝並登入它，再回來打開。」按鈕不動作 |
| 工具還沒登入 | 「命令列 AI 工具還沒登入。請在終端機登入它，再回來打開。」 |
| 開著、等問題 | 「開著：有問題時會自動回答。」（AI 卡片仍顯示伺服器知道的事實：上次連線時間、是否暫停） |
| 開著、正在回答 | 「正在回答一個問題。」 |
| 連線碼被拒絕 | 「伺服器不接受這把連線碼（可能已撤銷）。請關掉再重新打開。」 |
| 連不上 | 「連不上伺服器，會自動再試。」 |
| 關著 | 按鈕「用這台電腦上的 AI 回答」 |
| 對象 B 存好後 | 顯示網址與「開著」，沒有連線碼可看 |

## 6. 沒做的（誠實列出）

- 沒有用真的、已登入的 AI 工具與真的桌面版打包測過（雲端環境做不到）；測的是假工具與主程序邏輯。
- Linux 沒有鑰匙圈時 `safeStorage` 只有弱保護：這種情況**不開**，並說明原因。
- macOS／Windows 桌面版沒有建置，路徑未驗證。
- B 的 (b) 配對、進度（思考／動作）轉成伺服器事件、App 關閉後仍在背景回答：都沒做。
