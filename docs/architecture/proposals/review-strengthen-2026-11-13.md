# 提案：複習加強（挖空出題、複習畫面、以範圍練習、狀況頁）

> 狀態：現行（最後確認 2026-11-13）

> 2026-11-13。**設計提案**；只寫文件，不含程式。業主同日確認第 2 節的決定。
> 相關：[標籤不擁有功能，功能把標籤當範圍](tag-as-scope-2026-11-13.md)、[功能引用第三批的補充](function-refs-b3-2026-11-12.md)（複習的段落與筆記改記引用）。
> 手機示意（業主看過）：claude.ai 上的 artifact「Onden 複習手機示意」。

## 1. 為什麼

排程（FSRS、四個評分）是夠的，弱的是排程的前後兩端：

- **出題麻煩**：一張卡要嘛是整則筆記或整個段落，要嘛照 `Q:`／`A:` 另外寫、再按「抓題」生出子筆記。
- **複習時和原文脫節**：答完看不到前後文，不能當場改。
- **看不到狀況**：只有「今天幾張到期」。

## 2. 業主的決定（2026-11-13）

1. **挖空**：手機上點一個詞就遮住，按住拖曳遮一段（Readwise 的手勢）。卡片就是原段落，不另外生筆記。
2. **遮蓋的記號只是資料**：複習功能開著、而且這一段是複習卡時，才顯示成提示；複習關掉時就是普通文字，不留任何痕跡，記號保留。
3. **記號存在段落文字裡**，平常看不到（和段落 id 的處理方式相同）；匯出 Markdown 時寫成 `==…==`。
4. **評分留四個**，按鈕上寫出下次多久後再出現。
5. 以標籤或一棵樹為範圍來練（[另一份提案](tag-as-scope-2026-11-13.md)）。

## 3. 設計

### 3.1 挖空

- 一塊連續的遮蓋＝一張卡。同一段有幾塊就有幾張，各自排程；**同一天只出其中一張**（其餘順延到隔天），避免前一張洩漏後一張。不做編號。
- 遮下第一塊時，這一段同時成為複習卡（寫入這個段落的複習引用）；最後一塊取消時引用移除。**排程紀錄保留**，之後再遮回來不從頭算。
- 排程的鍵是「段落 id＋這一塊自己的固定 id」，id 寫在記號裡；不用字元位置，也不把排程寫進文字。文字怎麼改，只要記號還在，卡片就還在。
- 記號被刪掉（那幾個字整個刪除）＝那張卡沒有了；它的排程紀錄留著不顯示，不主動清。
- 整段都沒有遮蓋的複習卡（現在的做法）繼續有效：題目是段落的第一行或標題，答案是其餘部分。
- 編輯器：桌面選字後在選取工具列出現「遮住」；手機點詞、按住拖曳。只在複習功能開著時出現。
- `Q:`／`A:`「抓題」先保留不動；挖空上線並用過一段時間後，再問業主要不要拿掉。

### 3.2 複習畫面

- 答案揭曉後顯示：來源筆記的名稱、前一段與後一段。
- 看得到的動作（不藏在 ⋯ 裡）：開啟原文（跳到那一段）、改這段（當場編輯）、明天再說（不評分）、先不複習這張（停用，可在筆記裡恢復）。
- 四個評分各寫下次的間隔。
- 上一張可以復原。

### 3.3 以範圍練習

- 筆記頁與標籤頁各一個看得到的入口「複習這裡的卡片（N 張）」，沒有卡片時不顯示。
- 不看到期日，把範圍內的卡片過一遍；評分照常進排程。
- 範圍的定義照[標籤當範圍](tag-as-scope-2026-11-13.md)第 5 節，前後端各只有一個實作。後端的清單與統計已經接受「一棵樹」與「一個標籤」兩種範圍。
- 標籤頁另有一次性的「把這裡的筆記設成複習卡」。

### 3.4 狀況頁

- 今天要複習幾張；前幾天沒做完的另外標出，不混在預測裡。
- 未來七天的量。
- 常忘的卡（忘了 N 次以上）：按鈕直接帶去改那一段，不是停用。
- 每天最多幾張，超過的順延；個人設定。

## 4. 順序與相依

| 步驟 | 內容 | 相依 |
|---|---|---|
| 1 | 複習畫面（3.2）與狀況頁（3.4） | 無，可先做 |
| 2 | 以範圍練習（3.3）＋共用的範圍定義 | 無 |
| 3 | 挖空（3.1） | 等第三批把「段落是複習卡」改記成引用之後再做，免得建在即將拿掉的標籤做法上 |

每一步各一個 PR；會改資料形狀的只有第 3 步。

## 5. 不做

- 依個人作答紀錄調整排程參數、記憶率設定。
- AI 自動出題（等出題方式定了再接）。
- 不評分的回顧（Readwise 那種「近期再看／晚點／不用了」）：需要第二條較鬆的排程，列為之後的題目。
- 圖片遮蓋。

## 6. 別家的做法（2026-11-13 調查摘要）

- 筆記型的（RemNote、Logseq、Obsidian 的複習外掛）卡片就是筆記文字；Anki、Readwise、SuperMemo 另存一份，共同的問題是原文改了卡片不會跟著改。
- 手機上最順的出題手勢是 Readwise 的點詞遮住、按住拖曳。
- Anki、RemNote 四個評分並寫出間隔；Mochi 兩個；Obsidian 外掛三個。
- 不評分先跳過、停用一張卡，幾乎每家都有。
- Anki 的預測圖不含過期的卡；它對常忘的卡的官方建議是改寫。
- Obsidian 外掛把排程寫進筆記文字，筆記會變髒——本設計不這樣做。
- 同一段多個挖空要錯開（Anki 的 sibling burying）。
