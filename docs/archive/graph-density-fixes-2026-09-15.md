# 白板密度與閱讀實測（2026-09-15）

> 狀態：歷史紀錄（最後確認 2026-11-01）

使用者希望日後用 Onden 的筆記、圖及 tag 能力解釋程式架構；本次釐清眼前問題是「圖上筆記卡片太多，內容和連線擠在一起」。完成範圍是同一張白板的總覽、選取閱讀、縮放與精簡切換，不建立架構範本。

## 確認的問題與修改

- `useGraphLayout` 的正文 hashtag 提示原本兩兩連線：20 張共享兩個標籤時會有 380 條虛擬線。改成選取卡片到其他可見同伴的 19 條提示，共同標籤合併，不改已保存的語意邊。
- 連線寬 22px 的透明點擊範圍在卡片上方，滑鼠點卡片實際選到線。卡片現在高於這些互動路徑。
- `KnowledgeWorkspace` 的精簡顯示先收起正文，選取時展開一張，並只呈現其相關連線。12 張起預設精簡，可取消；顯示高度為 72px，保存尺寸不變。
- 原本內容變更或重新渲染也會重新置中，普通點擊又累積先前選取，使對齊工具列冒出。現在只有新選取置中，普通點擊取代選取；精簡圖選取時至少 1×，Fit 可縮到 0.1×。
- 卡片原本內層固定 260px、長正文超出保存高度。現在跟隨保存寬高、正文內部捲動；選取後可直接在卡片內編輯。縮放不會卸載使用中的編輯器。
- 手機工具列縮成一列橫向捲動，按鈕 44px；隱藏會遮住密度按鈕的桌面 inspector 收合 stub。
- 全域／局部力導向圖原本 Canvas 採整個視窗寬度，1440px 測試中 1164px 容器卻裝 1280px 畫布而被裁切。加入 ResizeObserver、容器寬高和 Fit 控制；選取保留圖物件，文字色與底色取目前主題。

## 限制

- 密度偏好只屬於目前白板畫面生命週期；不移動或重新排列已重疊的卡片，也沒有新增自動分群。
- 共同標籤提示仍根據正文 hashtag；不是 class-tag 插件依賴圖或權限圖。架構視覺化內容仍是後續使用目標。
- 本批沒有盤完白板多步 undo、群組拖曳、撤權、同帳號多分頁和真機觸控／輸入法；CAN-08 維持「部分」。
- 工作區與隔離開發服務的驗證不等於 Docker 正式前端已部署。
