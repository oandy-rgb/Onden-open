## 使用契約與責任

兩端共用以下順序，不增加子選單：

| 分組 | 由左至右、由上至下 |
| --- | --- |
| 日常 | 今日筆記、搜尋、閱讀、複習 |
| 整理與發布 | 白板、關係圖、標籤、網站 |
| 工具 | 詢問筆記、重新整理、設定 |

「閱讀」仍開啟原訂閱／稍後讀介面；「詢問筆記」使用原詢問入口。詢問與
重新整理仍須有對應 callback 才出現。桌面額外釘選檢視保留完整名稱，
置於獨立單欄分組；手機帳號、同步及忙碌狀態的禁止操作維持原契約。

比較由兩個畫面各自加分類與擴充共用清單後，選擇
`getMoreNavigationGroups(callbacks)`。它回傳 `{ id, label, items }[]`，
items 保留既有 id、翻譯 key、圖示與 callback；分類和順序只需修改一處，
兩端不再分別理解哪個功能屬於哪組。呼叫方式例如
`getMoreNavigationGroups({ setMode, onOpenDailyNote, onOpenSearch, onOpenCanvas, ... })`；
實際 handler 不變，外殼仍負責關閉、焦點、翻譯與忙碌防護。
未新增通用選單框架或把帳號／保存流程移入清單。

桌面面板寬360px、一般列高至少38px、粗指標至少44px；手機每組雙欄，
圖示在左、文字在右、操作至少44px。小標題區分類別，桌面淡線區分組。
手機標題與關閉按鈕固定在捲動區上緣，短畫面可繼續捲至底部設定。
雙欄桌面上下鍵移至相鄰列的同欄，遇單項末列就落在該項；左右鍵依閱讀
順序移動，Home／End移至首末項，Escape關閉並返回更多按鈕。

新增筆記34px按鈕、閱讀17px／680px及原有頂列入口沿用前一輪設定。
這些分組與尺寸是本產品選擇，不宣稱已證明比單欄搜尋更快。
