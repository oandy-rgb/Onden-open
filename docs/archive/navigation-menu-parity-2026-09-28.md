# 桌面／手機更多選單與新增筆記（2026-09-28）

> 狀態：已被取代（by navigation-entry-deduplication-2026-09-29.md）（最後確認 2026-11-01）

起點 `cd87dcb`，實作提交 `d21b9a2`。使用者指出桌面「更多」應與手機功能一致，並確認問題是
頂部 New 按鈕的文字與外觀。本輪只調整這兩個入口。

## 行為與設計

比較複製手機清單到桌面，以及共用清單後，採用
`getMoreNavigationItems(callbacks)`：回傳有序的 id、翻譯 key、圖示與動作。
例如兩端傳入同一個 `onOpenCanvas`，選取白板時都開目前筆記的白板檢視；
清單不處理保存、建立筆記、帳號或授權。原本新增一項功能要分別維護兩份
名稱、圖示與接線，現在只改一份清單；桌面選單鍵盤／關閉與手機對話框／
忙碌防護仍由各自外殼擁有。

兩端「更多」功能順序為今天、搜尋、白板、複習、讀、關係圖、標籤、網站、
詢問、重新整理、設定。詢問與重新整理仍在有 handler 時才提供。
桌面保留額外釘選標籤；帳號與同步保留桌面右上角及手機對話框原有位置。
桌面常用導航與原有手機底列不重排。

新增筆記改為「＋ 新增筆記」，使用已有的 `Create new note` 翻譯，補齊
快捷鍵提示。改用較淡的強調背景及邊框、繼承工具列字體，高度34px且不換行，
與今天按鈕相同；仍送出同一個 quick-capture 事件，不更換保存流程。
