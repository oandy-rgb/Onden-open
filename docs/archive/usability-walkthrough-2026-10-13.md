## P0：資料遺失，或功能沒做到它說的事

| # | 問題 | 重現方式 |
|---|---|---|
| F1 | PDF 手寫只在按「停止繪製」時才存 | 畫一筆、等 6 秒都沒有寫入；按停止後才 PUT `ink_data` 和 `pdf_annotations`。在繪製模式下離開頁面，筆跡就沒了 |
| F2 | RSS 文章存成筆記後，內容是原始 HTML | 閱讀器 → 劃線存卡片，或「存成筆記」→ 開啟筆記 |
| F3 | 「將劃線存成卡片」後，卡片沒有進入複習 | 已引入複習模組，存完卡片後打開複習頁，顯示「目前沒有要複習的卡片」 |
| F4 | 教學說 `- [ ]` 會變成任務，實際上不會 | 在筆記裡打兩個待辦，`/api/tasks/agenda` 回傳 `count: 0` |
| F5 | 快速捕捉按 Esc 會直接丟掉草稿 | 打字後按 Esc，不會確認也不會保留；快速捕捉裡也沒有 `[[` 自動完成 |
| F6 | 白板雙擊建立的卡片，標題無法輸入 | 焦點落在 `.onden-note-detail`，留下一張標題為「New Note」的空卡片 |

## P1：找不到、看不懂、要繞路

- F7：手寫有三套工具（白板手寫、PDF 手寫、Excalidraw）。
  - PDF 只能拖進編輯器；手繪只能從 ⌘K 建立。
  - `/` 選單的 17 項裡沒有插入類項目。
  - Excalidraw 介面沒有翻譯。
- F8：RSS、複習、文獻都要先到「標籤 › 模組庫」引入，才會出現在導覽列。
- F9：系統自動產生的節點把側欄塞滿：白板、白板卡片、RSS 來源、劃線卡片、草圖。
- F10：「閱讀」只有 RSS；「只看沒看過的」預設勾選，剛讀過的文章會從列表消失。
- F11：
  - 第一個畫面就要選資料存放位置。
  - 「新增筆記」其實是快速捕捉。
  - 捕捉時標題裡的 `#tag` 不會被移除，`@today` 會變成 `due_date`。
  - 中文筆記顯示「2 詞」。

## P2：需要打磨

- 英文預設名稱：Untitled Canvas、New Note、Library。
- 白板有 18 個只有圖示的按鈕。
- 編輯器看得到 Markdown 標記，還要在編輯和預覽之間切換。
- 第一次載入時有一個 404 的版本請求，並跳出「已建立」toast。
- 手機版筆記頂端的控制元件太佔空間。
- PDF 的「N 個標註」不計入手寫。
