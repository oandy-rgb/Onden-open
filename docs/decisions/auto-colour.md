# 自動配色：兩個種子色產生全部 app 顏色

> 狀態：現行（最後確認 2026-11-01）

| 項目 | 內容 |
| --- | --- |
| 日期 | 2026-10-30（業主決定，2026 年） |

## 決定

使用者只選兩個種子色（強調色與底色），其餘 app 顏色由公式算出；預設使用者不存任何東西。

## 為什麼

手選每個顏色容易失衡，也無法保證對比。

## 例外

CSS 只准讀 `var(--ac-*)`。
