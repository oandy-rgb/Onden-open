# 「隱藏」只用在標籤

> 狀態：現行（最後確認 2026-11-01）

| 項目 | 內容 |
| --- | --- |
| 日期 | 2026-10-19（業主決定，2026 年） |
| 實作狀態 | **已定案（未逐項對照程式）** |

## 決定

只有標籤有「隱藏」。app 自動建的節點（例如任務、段落節點）不靠隱藏旗標，而由側欄整理規則排除。

## 為什麼

隱藏若到處都有，使用者分不清「不見了」是被刪還是被藏。
