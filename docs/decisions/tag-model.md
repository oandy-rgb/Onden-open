## 決定

1) 繼承只有階層，功能靠組合（10-18）。2) 標籤不是狀態：標籤是自己的主題，狀態是筆記上的開關（10-30）。3) 內文的 `#tag` 刻意不替筆記加標籤（10-24）。4) 分層是 功能→標籤→筆記，模組標籤不進標籤樹（10-24）。

## 為什麼

把「分類」「功能」「狀態」混在一種東西裡，會讓標籤頁既當目錄又當設定。
