## 決定

每個空間有一篇任務筆記（不在筆記樹裡）；日記與 RSS 訂閱維持個人，不隨空間共享。

## 為什麼

任務要跟著空間的成員共享；日記與閱讀是個人的。

## 例外

—

## 個人空間不知道時（2026-11-22）

沒指定筆記的任務放哪由 `dayNotes.openTaskHome` 一處決定（個人空間 → 今天的日記或個人的「任務」，共享空間 → 該空間的「任務」）。
個人空間的 id 跟著本機副本保存，離線也知道；只有從沒聽過伺服器的裝置不知道，這時不建任何一篇、說一句白話、保留輸入，
不再用隨機 id 建出第二篇「任務」或把個人空間當成共享空間。
