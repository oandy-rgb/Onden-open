# 盲測評價：介面與互動設計評審（2026-11-02）

> 狀態：歷史紀錄（最後確認 2026-11-02）

**視角**：資深產品設計師，用 Nielsen 十大可用性原則與 Apple HIG／Material 做啟發式評估。
**對象**：`origin/main` 的 `build:browser` 純前端版（試用版，資料存在瀏覽器）。
**方法**：Playwright + Chromium（雲端沒有 WebKit，只測 Chromium）。桌機 1280×800、手機 **390×844 為模擬視窗（含觸控與 `isMobile`），不是真機**；淺色與深色都看。瀏覽器語言預設 `en-US`，另外用 `zh-TW` 看過首頁一次。
**盲測規則**：評價前沒有讀 `docs/`、`AGENTS.md`、`changes/`、git log、PR／issue；只照 `package.json` 的指令建置、啟動。看到 bug 後才讀程式找位置（只附位置，沒有影響評分）。**沒有改任何產品程式。**

## 4. 截長補短

### 這個 App 比別人好、應該保留

1. **指令面板的「一個框、四種模式」**（`Ctrl+K`，前綴 `#` 標籤、`>` 指令、`?` 全文）：比 Notion 的 Quick Find、Apple 備忘錄只能搜尋都更順手，且面板底部有常駐的操作提示（Navigate／Select／esc）。保留，並把這個提示語法放進空狀態。
2. **新建筆記時一起選位置與種類**（「Put it in: Only me › Top level」＋「Just one line? Quick capture Ctrl+Shift+N」）：Things／Todoist 的 Quick Entry 只管內容，這裡把「放哪裡」說清楚；Inbox 與 Quick capture 對應 GTD，比 Google Keep 更有去處。
3. **手機底部抽屜與分段式選單**：「Add a view／This note」抽屜有分組標題與大點擊面積，比 Obsidian Mobile 的選單易按。
4. **深色與淺色主題一致**：同一組暖色，深色主題沒有出現對比壞掉的區塊（`design-40-dark-note.png`、`design-45-m-dark-note.png`），做得比不少 Electron 筆記軟體細。
5. **同一篇筆記可以切換成 Table／Board／Calendar／Cards／Slides 視角**：概念接近 Notion／Heptabase／Anytype 的資料庫視圖，但入口在筆記本身而非另開資料庫；這個定位值得保留（我只看了選單，視角本身**沒試**）。
6. **試用版直接在瀏覽器跑、不需註冊**：比 Notion／Craft 的首次上手阻力低很多。

### 它們做得好、這個 App 該學

1. **Notion／Apple 備忘錄：標題 Enter 進內文，`Untitled` 只是 placeholder。** 為什麼：每篇筆記都會碰到，現在是第一個摩擦。做法：標題欄用 placeholder 屬性；Enter 把焦點交給內文第一行；空標題在側欄顯示灰字「未命名」。
2. **Obsidian Live Preview：只在游標所在行顯示 Markdown 符號。** 為什麼：保留 Markdown 可攜性，又讓畫面像成品。做法：已有符號 decoration，改成「選取行以外隱藏」，清單轉圓點、`- [ ]` 轉核取方塊。
3. **Things 3／Todoist：空狀態教人下一步，Today 只列今天。** 為什麼：Tasks 現在是一片時間軸。做法：Today 空時顯示一句話＋輸入框；Timeline 預設折疊成「顯示時間軸」，放在「Today」之後。
4. **Logseq／Obsidian 的圖譜：預設只顯示有連結的節點、可過濾標籤、節點大小依連結數、label 碰撞避讓。** 為什麼：目前 16 個節點就糊成一團。做法：預設濾掉 0 連結節點，標籤改成可開關的第二層，使用 d3-force 的 collide 半徑＝label 寬度。
5. **Bear／Craft 的通知與提示原則：一次一個、不蓋 modal。** 為什麼：What's new 與 Trial toast 同時壓住內容。做法：只留一個「提示隊列」，modal 開啟時全部暫停；「更新紀錄」放在設定與「？」選單，只在側欄角落放小紅點。
6. **Apple HIG／Material 的點擊目標**：把元資料列（只有我／Tag）放大到 ≥32px（桌機）／44px（手機），或整列可點。
7. **Notion 的頭像選單**：直接列出「設定／切換工作區／登出」，不再多開一層 Account 對話框。

## 5. 前 5 個最該先修的

1. **新筆記標題的 `Untitled` 真字與 Enter 不進內文（#1）**：每個使用者第一次寫筆記就撞到，會讓人以為輸入壞了。
2. **What's new 疊在 modal／抽屜之上，且 Trial toast 蓋住手機操作（#2、#3）**：兩個浮層互相遮蔽，破壞「存好了沒」「這是什麼」的主要回饋。
3. **冷開自動建立空白「今天」筆記並把它當第一屏（#9）**：第一印象是一篇沒人要的空筆記；改成歡迎頁並延後建立。
4. **右欄與設定術語（Functions／Relations／Put under…／Spaces and members／Synced）（#10、#11）**：新使用者看不懂，也無從判斷哪些功能在試用版可用。
5. **標籤清單與標籤選單的行為（#12）**：整理是核心使用情境，展開未使用標籤後常用標籤消失，直接破壞可預測性。
